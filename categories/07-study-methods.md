## Resources
### Anki

- Link: https://apps.ankiweb.net/
- Category: Study Methods / Spaced Repetition
- Use Case: Build spaced repetition flashcards for vocabulary, grammar patterns, exam phrases, and long-term memory.
- Strengths: Powerful memory system, highly customizable, strong for long-term retention.
- Limitations: Requires consistent review and good card design; poor cards reduce effectiveness.
- Relevance to Specularis: Useful for building a durable memory layer for English, exams, and long-term skill acquisition.
- Notes: Best used with active recall, example sentences, and regular review.
