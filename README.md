# Specularis Learning Lab

**English learning, exam preparation, skill acquisition, and cognitive systems.**

Specularis Learning Lab is a curated research index for language learning, exam preparation, self-learning methods, cognitive systems, and long-term skill acquisition.

This repository does not redistribute third-party content. It only links to original resources and includes personal research notes for learning, evaluation, and system design.

## Purpose

The purpose of this lab is to build a long-term learning archive that supports:

- English learning
- PTE / IELTS preparation
- Listening improvement
- Speaking practice
- Writing development
- Grammar foundation
- Study methods
- Skill acquisition systems

## Structure

| Area | Focus |
|---|---|
| English Learning | General English learning resources, courses, tools, and learning systems |
| PTE / IELTS | Exam preparation, scoring criteria, practice resources, and test strategies |
| Listening | Listening comprehension, shadowing, dictation, and input systems |
| Speaking | Pronunciation, fluency, oral response, and speaking frameworks |
| Writing | Essay writing, sentence structure, academic writing, and expression |
| Grammar | Grammar foundations, sentence patterns, error correction, and syntax |
| Study Methods | Learning systems, memory methods, deliberate practice, and skill roadmaps |
