# Learning Resource Evaluation Framework

A structured framework for evaluating English learning, exam preparation, study methods, and skill acquisition resources.

The goal is not to collect as many learning resources as possible, but to identify resources that can improve long-term learning systems.

## Evaluation Criteria

| Criteria | Question |
|---|---|
| Source Quality | Is the resource from a credible, original, or well-maintained source? |
| Structure | Is the content well-organized and easy to follow? |
| Practical Value | Can it be turned into actual learning routines or workflows? |
| Relevance | Does it support English learning, exam preparation, or skill acquisition? |
| Depth | Does it provide deeper principles instead of shallow tips? |
| Actionability | Can I apply it immediately or convert it into a system? |
| AI Integration | Does it support AI-assisted learning or workflow design? |
| Sustainability | Can the method be used long term? |
| License / Usage | Are copyright and usage terms clear? |

## Scoring System

| Score | Meaning |
|---|---|
| 1 | Low value / avoid |
| 2 | Interesting but weak |
| 3 | Useful reference |
| 4 | Strong learning resource |
| 5 | Core resource worth deep study |
